Исходный код приложения "Планировщик задач" и установщика для него.

Данное приложение позволяет создавать задачи с различным приоритетом, отслеживать статус их выполнения, группировать задачи по разделам и объединять в подзадачи. Создано в учебных целях.

Для установки релизной версии приложения следует скачать и запустить файл "TaskManager.Installer.msi". После установки на рабочем столе и в меню "Пуск" появятся ярлыки приложения, и оно будет готово к использованию.
